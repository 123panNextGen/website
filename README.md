# 123Pan NextGen 官方网站

## 技术栈

- **Vue 3** — Composition API + `<script setup>`
- **TypeScript** — 类型安全
- **Vite** — 极速构建

## 本地开发

```bash
npm install
npm run dev      # 启动开发服务器
npm run build    # 生产构建
npm run preview  # 预览生产构建
```
